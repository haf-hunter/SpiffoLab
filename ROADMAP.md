# SpiffoLab CC — Public Roadmap

Here is what we are working on next for **SpiffoLab CC** (Project Zomboid Build 41 & Build 42).  
Have a feature request or bug report? Open an issue anytime in our [Issue Tracker](https://github.com/haf-hunter/SpiffoLab/issues).

---

## Planned & In Progress

### 1. One-Click Presets for Historical Game Builds (B19 – B40)
- Ready-to-play profile presets for classic Project Zomboid builds going all the way back to 2013 (Build 19 through Build 40).
- Automatic launch support for older builds that predate modern launcher configs, plus guided hints for matching legacy Java versions.

### 2. Smarter Theme Engine & Visual Polish
- Unified color tokens across all views, live charts, help pages, and exported diagnostic reports so new themes work seamlessly everywhere.

### 3. Enhanced In-Game Crash Protection & Reporting
- Deeper integration with ZombieBuddy crash protection so prevented in-game crashes are surfaced clearly in the Live Log and Diagnostic Report.

---

## Recently Completed

- **v2.5.2:** Self-contained Windows installer (no extra runtime needed), per-profile external optimizer support, improved Zombie AI telemetry, and Workshop mod hotfix.
- **v2.5.0 – v2.5.1:** New 1-click `TUNING` tab, reliable live GPU Load and dedicated VRAM tracking, clean idle metric reset, and external optimizer conflict warnings.
- **v2.4.0 – v2.4.1:** Built-in 24-Build Game Downloader (B19 – B42) with Steam Guard support and safer profile switching.
- **v2.0.0 – v2.3.4:** 4 color themes, full 4-language support (`EN`, `DE`, `ES`, `PT`), guided setup wizard, and one-click signed in-app updates.

For the full version-by-version history, see [CHANGELOG.md](CHANGELOG.md).
